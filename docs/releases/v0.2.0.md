# HTVL v0.2.0 — the compiler is back

_The 2020 prototype was two lines of obfuscated bash that `eval`'d heredocs,
with a trial timer and a `sudo` call. HTVL is now a small, readable, tested
Python compiler — and it compiles your old files to exactly the same bytes._

## Install

```bash
pip install .          # console script: htvl
```

## Highlights

- **A grammar you can audit** — every tag and variable is declared in one
  table (`htvl/elements.py`, `htvl/variables.py`) with documentation.
  There is no packed string left anywhere in the repo.
- **Byte-for-byte backwards compatible** — `tests/test_golden.py` compiles
  the original 2020 example and asserts the output is identical, down to the
  empty attributes and cosmetic quirks. `legacy/` keeps the prototype, its
  README, and a de-obfuscated copy of its compiler as the grammar reference.
- **Modern output, opt-in** — `htvl compile --modern` emits clean HTML: no
  empty attributes, HTML-escaped text, no stray spaces. Same source files,
  same line structure; the diff between modes is the whole story.
- **Watch mode** — `htvl compile --watch` keeps your output current:
  incremental rebuilds per edited file, template changes rebuild the project,
  deletions remove outputs, and a broken edit never kills the watcher.
- **Editor support** — a VS Code extension (`editors/vscode/`, packable with
  `npx @vscode/vsce package`) and a Pygments lexer (`extras/`).
- **A serverless playground** — `playground/` runs the real compiler in your
  browser via Pyodide, with a legacy/modern toggle.

## What changed from the prototype

| | 2020 bash | v0.2.0 Python |
| --- | --- | --- |
| Source | 2 lines, obfuscated + `eval` | ~1,700 readable lines |
| Unknown tag/variable | silent or empty output | error with file, line, column |
| Trial expiry | 90-day timer, expiry message | removed |
| Asset copy | `sudo cp` | plain `shutil.copytree` |
| Existing projects | — | compile byte-identically |
| Tests | none | 136 |

## Quickstart

```bash
htvl new mysite
cd mysite
htvl compile             # -> public/index.html
htvl compile --watch     # keep it compiled as you edit
```

The language reference is in [`docs/grammar.md`](docs/grammar.md):
`$(h 1 '' '' 'Hello' '')`, `$head` / `$_a` / `$meta`, templates, and `.cal`
CGI output.

## Breaking changes

None by default: the CLI, the `.htvl` grammar, the `templates/*.sh` format and
the emitted HTML are all unchanged. The foot-guns (trial timer, `sudo`,
silent failures) are gone.
