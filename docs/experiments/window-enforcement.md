## 5. Threats and limitations

- **Construct:** the dependent variable is *compiles*, which is necessary but not sufficient for correctness. This experiment measures **well-formedness, not content quality**.
- **Tokens as cost:** a proxy. Excludes latency, transport retries and human review time.
- **Prompt confound is the treatment:** Arm B sees diagnostics and Arm A does not, by design; both share the base prompt.
- **External validity:** one model family, English intents, HTML-shaped documents.
- **Decoding is greedy (temperature 0), so the ablation arm draws three identical samples: best-of-k equals first-sample by construction. Arm C is reported for completeness but cannot separate selection from repair under these settings.**

## 6. Verdict

**SUPPORT.** R = 0.1679 with 95% CI (0.0686, 0.3838). Per the pre-registered rule: SUPPORT (R<=0.80, upper CI<1.00) ships htvl-mcp; REFUTE (R>=1.20, lower CI>1.00) does not; otherwise INCONCLUSIVE is published as a null result.

## 7. Reproduction

```bash
pip install -e ./imprimatur-eval    # or: export PYTHONPATH=imprimatur-eval
python -m imprimatur_eval build --out data.jsonl --model ollama/qwen2.5-coder:7b-instruct
python -m imprimatur_eval repair --in data.jsonl --out traces.jsonl --sft-out sft.jsonl
python -m imprimatur_eval ab --model ollama/qwen2.5-coder:7b-instruct --tasks imprimatur-eval/tasks.jsonl --report RESULTS.md --json-out results.json
```

Every number above is machine output from those three commands; the raw report dict (per-task rows included) is the --json-out file.

Deviations from the pre-registered protocol are logged in docs/experiment-deviations.md.
